# 나락의 징검다리

순수 HTML5 Canvas + 바닐라 JavaScript로 만든 2D 점프맵 게임. `index.html` 하나만 브라우저로 열면 바로 실행됩니다.

## 플레이

- 온라인: https://leewonyoungethan.github.io/jumpmap/
- 오프라인: 위 주소에 한 번 접속하면 게임이 저장되어 인터넷 없이도 실행됩니다. 홈 화면에 추가하면 앱처럼 쓸 수 있어요.
  - 안드로이드 Chrome: 메뉴 ⋮ → **홈 화면에 추가** (또는 **앱 설치**)
  - 아이폰 Safari: 공유 버튼 → **홈 화면에 추가**
  - PC Chrome/Edge: 주소창 오른쪽의 설치 아이콘
- `index.html` 파일만 받아서 더블클릭해도 오프라인으로 바로 실행됩니다.

## 조작법

| 키 | 동작 |
|---|---|
| ← → / A D | 이동 |
| Space / ↑ / W | 점프 (길게 누르면 더 높이) |
| Enter | 게임 오버 시 체크포인트에서 재시작 / 클리어 후 다음 스테이지 |
| R | 이 스테이지 처음부터 |
| Esc | 메인 메뉴 |

**모바일**: 가로 화면에서 왼쪽 아래 ◀ ▶ 로 이동, 오른쪽 아래 **점프** 버튼(길게 누르면 더 높이), ↺ 는 다시하기, ☰ 는 메뉴. 죽었을 때는 화면을 터치하면 체크포인트에서 다시 시작.

## 스테이지

1. **첫 걸음**: 용암, 가시, 움직이는 발판을 익히는 입문 스테이지
2. **무너지는 다리**: 대부분이 함정 발판인 나락 위 다리
3. **나락의 심장**: 용암 위에서 꼭대기까지 올라가는 수직 스테이지

스테이지를 깨면 다음 스테이지가 열리고, 스테이지별 최고 기록이 저장됩니다.

## 캐릭터 꾸미기

메인 메뉴에서 색깔 9가지와 무늬 7가지(없음, 줄무늬, 물방울, 체크, 지그재그, 별, 배)를 고를 수 있어요. 고른 캐릭터와 진행도는 브라우저에 저장됩니다.

## 요소

- **나무 발판**: 아래에서는 통과, 위에서만 밟을 수 있음
- **움직이는 발판**: 올라타면 함께 이동
- **함정 발판 (금 간 돌)**: 밟으면 1초 동안 붉게 변하며 흔들리다 부서지고, 3초 뒤 복구
- **체크포인트 깃발**: 가장 최근에 닿은 깃발이 부활 지점
- **나락**: 바닥 없는 구간으로 떨어지면 사망 없이 마지막 체크포인트로 즉시 구조
- **가시 / 용암**: 즉시 게임 오버
- **초록 포털**: 도착 지점 — 닿으면 클리어
