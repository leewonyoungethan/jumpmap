# 점프맵 플랫포머

순수 HTML5 Canvas + 바닐라 JavaScript로 만든 2D 점프맵 게임. `index.html` 하나만 브라우저로 열면 바로 실행됩니다.

## 조작법

| 키 | 동작 |
|---|---|
| ← → / A D | 이동 |
| Space / ↑ / W | 점프 (길게 누르면 더 높이) |
| Enter | 게임 오버 시 체크포인트에서 재시작 / 클리어 후 처음부터 |
| R | 언제든 처음부터 |

## 요소

- **나무 발판**: 아래에서는 통과, 위에서만 밟을 수 있음
- **움직이는 발판**: 올라타면 함께 이동
- **체크포인트 깃발**: 닿으면 활성화, 죽으면 여기서 부활
- **가시 / 용암 / 추락**: 즉시 게임 오버
- **초록 포털**: 도착 지점 — 닿으면 클리어
