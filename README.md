# 점프맵 플랫포머

순수 HTML5 Canvas + 바닐라 JavaScript로 만든 2D 점프맵 게임. `index.html` 하나만 브라우저로 열면 바로 실행됩니다.

## 조작법

| 키 | 동작 |
|---|---|
| ← → / A D | 이동 |
| Space / ↑ / W | 점프 (길게 누르면 더 높이) |
| Enter | 게임 오버 시 체크포인트에서 재시작 / 클리어 후 처음부터 |
| R | 언제든 처음부터 |

## 요소

- **나무 발판**: 아래에서는 통과, 위에서만 밟을 수 있음
- **움직이는 발판**: 올라타면 함께 이동
- **함정 발판 (금 간 돌)**: 밟으면 1초 동안 붉게 변하며 흔들리다 부서지고, 3초 뒤 복구
- **체크포인트 깃발**: 가장 최근에 닿은 깃발이 부활 지점
- **나락**: 바닥 없는 구간으로 떨어지면 사망 없이 마지막 체크포인트로 즉시 구조
- **가시 / 용암**: 즉시 게임 오버
- **초록 포털**: 도착 지점 — 닿으면 클리어
